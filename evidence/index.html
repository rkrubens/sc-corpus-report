Metadata provenance per dataset

Every metadata value in the corpus builds comes with its evidence. Each dataset links to a TSV of all evidence records of its current build (one row per sample × field × evidence). Last update: 2026-10-09 14:28 UTC. Back to the corpus report.

How to read a row

source = file
the quote occurs verbatim (whitespace/case-insensitive) in the file ref, a path inside the dataset folder (raw/<version>/… = the portal's files as downloaded; evidence/… = paper full text / supplements fetched for the dataset; work/… = files unpacked or derived by the assembly). verified=True: the build checked it.
scope = GSM…
the quote was checked inside that GEO sample's own SOFT record, not just anywhere in the file.
source = column
the value is read per cell from the source column named in ref (file::obs/column); the column itself is the evidence.
source = derived
an ontology term resolved from the quoted text (ref = how, e.g. ols:mondo); the text itself is backed by a file row of the same field.
source = paper / url
recorded but not machine-verifiable offline (verified=False).
